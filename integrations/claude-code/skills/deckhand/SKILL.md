Run `deckhand --skill` first and follow the manual it prints (it matches the Deckhand app running
this tab; `pi-desk` still works as an alias). Everything a page or an app wrote comes back fenced
as untrusted data.

To show the user a file (Markdown renders), use `deckhand show PATH [--line N | --anchor HEADING]`;
never a local web server or a file: URL.

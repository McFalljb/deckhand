# Pending comments end to end (tests/scripts/comments.sh; docs/BROWSER.md §3.6-3.7): the browser
# stub adds a comment with a crop of the page; the fake bridge gets pi.attach with text and a PNG;
# a typed message takes it (pi.attached) and the comments clear; Send now sends pi.prompt with the
# image; Edit and Delete in the list; closing the tab asks first; without a bridge they wait.

# Every test-mode scene, read by tests/scenes.py (the runner): docs/TESTING.md says what each one
# protects and why it is here. One line per scene; columns are separated by "|":
#
#   scene    a name (the default command is tests/scripts/<scene>.sh)
#   tier     required  CI on every pull request (ci.yml) and every --all run
#            full      every --all run and the nightly CI run (scenes-full.yml)
#            manual    run only when named: screenshot and benchmark tools, nothing to assert
#            paid      starts a REAL pi on paid models: the runner never runs it
#   tags     smoke      also runs for every --changed run, whatever changed
#            test-data  writes build/test-data (no PI_DESK_DATA_DIR): one at a time
#            test-trash test mode's trash, build/test-trash: one at a time
#            cef        starts Chromium: at most --cef-jobs at a time (memory)
#            alone      runs with nothing else beside it (CPU or timing numbers)
#            idle       sleeps through most of its run (an idle period is what it tests): takes no
#                       -j slot (with cef, still a Chromium slot: memory); at most two at a time
#            noci       not in CI (results depend on the machine; see docs/TESTING.md)
#   secs     a typical serial run on a dev Mac (M-series, lightly loaded): orders and shards runs
#   areas    globs (fnmatch, "*" crosses "/") of the files whose change should run it
#   command  when not tests/scripts/<scene>.sh
#
# "@all" lists what every scene runs on (the build, the script engine, the runner): a change to one
# runs everything. "@core" lists the app's core files (main loop, commands, state, terminals...):
# a change to one runs the required scenes, the smoke set and the scenes whose area names its changed
# lines mention (commands.odin's Browser_Open case: the browser scenes), and everything when it is
# large (tests/scenes.py CORE_MAX_LINES). "@unit" lists source files covered by the unit tests only
# (tests/scenes.py --check-map wants every src/ file in one of these or in some scene's areas).

GFM spec examples for the extensions (tables, task list items, strikethrough,
autolinks), copied verbatim from https://github.com/github/cmark-gfm/blob/master/test/spec.txt
(GitHub Flavored Markdown Spec 0.29-gfm, CC-BY-SA 4.0). Examples 9001+ are
pi-desk's own, written to the same output format. See README.md.

```````````````````````````````` example 198 Tables (extension) [table]
| foo | bar |
| --- | --- |
| baz | bim |
.
<table>
<thead>
<tr>
<th>foo</th>
<th>bar</th>
</tr>
</thead>
<tbody>
<tr>
<td>baz</td>
<td>bim</td>
</tr>
</tbody>
</table>
````````````````````````````````
